Comprehensive Infrastructure as Code (IaC) and Observability Solution

1. Executive Summary

This project focuses on solving the challenges of cloud network administration and operations by fully automating the infrastructure provisioning process and establishing a real-time network traffic monitoring mechanism. The solution aims to eliminate error-prone manual configurations (Click-Ops) while providing the capability to quickly detect, alert, and remediate connectivity issues or security vulnerabilities.

Within the scope of this internship report, the network system is built and managed according to enterprise standards on the AWS platform:

  • Automation: Utilizing AWS CloudFormation to declare the entire network topology (VPC, Subnets, Route Tables, NAT Gateway) as code (IaC), combined with a CI/CD pipeline via AWS CodePipeline/CodeBuild for consistent deployment.
  • Monitoring & Analysis: Integrating VPC Flow Logs to push data to Amazon CloudWatch Logs Insights for detailed access flow analysis (ACCEPT/REJECT). Additionally, applying advanced diagnostic tools like AWS Reachability Analyzer and Network Access Analyzer to mathematically verify network paths and firewall integrity (Security Groups & NACLs).

2. Problem Statement

Current Issues

Operating network infrastructure via manual methods (Click-Ops) frequently leads to human errors, causing configuration drift to accumulate and making it difficult to trace changes[cite: 5]. As the system scales, the lack of visibility into internal traffic (east-west traffic) and the inability to automatically detect and alert on anomalous access expose the system to significant security risks and prolonged downtime[cite: 5].

Solution

The project centralizes the entire network infrastructure lifecycle through Infrastructure as Code (IaC) combined with a CI/CD pipeline[cite: 5]. All network changes are version-controlled via Git and automatically deployed using AWS CloudFormation[cite: 5]. Simultaneously, the system deeply integrates VPC Flow Logs, analyzed via CloudWatch Logs Insights, and uses AWS Reachability Analyzer to proactively monitor and verify network paths in real-time[cite: 5].

Benefits and Return on Investment (ROI)

  • Eliminates 90% of manual infrastructure configuration time and standardizes Dev/Staging/Prod environments[cite: 5].
  • Maintains architectural integrity by instantly detecting network configuration deviations (Stack Drift)[cite: 5].
  • Comprehensive data flow observability, allowing alerts for network attacks (like port scanning) within minutes[cite: 5].
  • Optimizes costs by automatically cleaning up unused network resources via IaC[cite: 5].

3. Solution Architecture

AWS Services Used[cite: 7]

Category Service Role
Network Amazon VPC, Internet/NAT Gateway, Route 53 Provides virtual private network, routing, and secure domain resolution[cite: 7].
Automation (IaC) AWS CloudFormation Declares and provisions all infrastructure resources as code (YAML)[cite: 7].
CI/CD Pipeline AWS CodePipeline, AWS CodeBuild Automated syntax testing (linting) and infrastructure deployment from Git[cite: 7].
Observability VPC Flow Logs, CloudWatch (Logs/Metrics/Alarms) Records network flow metadata, creates dashboards, and sets alert thresholds[cite: 7].
Security & Analysis Network Access Analyzer, Reachability Analyzer Mathematically verifies network paths, ensuring no unauthorized access[cite: 7].
Notifications Amazon SNS Sends immediate email/SMS alerts to administrators during network incidents[cite: 7].

Component Design[cite: 7]

  • IaC Repository: Network source code is stored in a Git repository. Any changes to Subnets or Security Groups require a Pull Request and review.
  • Deployment Pipeline (network-pipeline 📄): Connects directly to Git. When the code is valid, CodeBuild triggers CloudFormation to update the infrastructure without causing downtime.
  • Monitoring Engine: VPC Flow Logs collect network traffic metadata and push it to CloudWatch. Metric Filters will filter continuous REJECT actions to trigger SNS Alarms warning of Port Scanning risks.

4. Technical Implementation

Deployment Phases[cite: 8]

  1. Design & Analysis (Weeks 1–3): Review the current manual network structure, design a standard Multi-AZ architecture, and draw the network-architecture.drawio diagram 📄.
  2. IaC Development (Weeks 4–7): Write CloudFormation templates (infra/vpc-core.yaml 📄, infra/security.yaml 📄) to define Subnets, Route Tables, Security Groups[cite: 8].
  3. CI/CD Automation (Weeks 8–9): Set up AWS CodePipeline connected to Git, integrating the cfn-lint tool to automatically check for syntax errors before deployment[cite: 8].
  4. Monitoring & Optimization (Weeks 10–12): Enable VPC Flow Logs, build monitoring Dashboards on CloudWatch, configure CloudWatch Alarms, and run simulated disconnection tests to verify error catching capabilities[cite: 8].

Technical Requirements[cite: 8]

  • Local: Development environment with Git, AWS CLI, and the cfn-lint tool installed 📄[cite: 8].
  • AWS: Account with IAM admin privileges to create IAM Roles for the Pipeline, and permissions to operate VPC, CloudFormation, CodePipeline, and CloudWatch[cite: 8].
  • Third-party: GitHub/GitLab account to serve as the infrastructure source code repository[cite: 8].

6. Cost Estimation

Operational costs are primarily focused on always-on services and log storage. Below is the estimation (can be further optimized via Free Tier):

  • NAT Gateway: ~$32/month (The most expensive component in the network architecture).
  • VPC Flow Logs & CloudWatch: Depending on stored data volume (GB), estimated ~$5-10/month.
  • CodePipeline/CodeBuild: Within the Free Tier limits for personal/learning projects.
  • Total: ~$40-45/month for a standard lab environment. Or download the detailed budget estimate file from the AWS Pricing Calculator[cite: 9].

7. Risk Assessment

Risk Matrix[cite: 9]

Risk Impact Probability
IaC syntax error breaking active network connections High Medium[cite: 9]
CloudFormation Stack Drift due to manual edits Medium High[cite: 9]
CloudWatch Logs cost spike due to high log volume Medium Medium[cite: 9]
False Positives from SNS rules Low High[cite: 9]

Mitigation Strategies[cite: 9]

  • Always run automated testing (linting & validation) in CodePipeline before applying changes to the live environment[cite: 9].
  • Assign IAM Policies to lock down manual VPC edits on the Console, enforcing all configurations through IaC[cite: 9].
  • Set a Retention Period for CloudWatch Logs to 7-14 days to reduce storage costs[cite: 9].

8. Expected Outcomes

Technical Improvements[cite: 10]

  • Closed-loop management workflow: Push code -> CI/CD auto-checks -> Zero-downtime infrastructure deployment[cite: 10].
  • Centralized governance: The entire network topology is documented as code, making it easy to audit and rollback when necessary[cite: 10].
  • Real-time observability: Proactively monitor unauthorized access events instead of reacting passively[cite: 10].

Long-term Value[cite: 10]

  • Build a solid standard foundation (Network Landing Zone) for any future projects deployed on AWS[cite: 10].
  • Fully master the Cloud Network Operations (Cloud NetOps) mindset, a crucial skill for Systems / DevOps Engineers[cite: 10].
  • Easily scale out infrastructure to other Regions simply by changing environment variables in the code[cite: 10].
